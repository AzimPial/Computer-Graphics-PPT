01 · Background

The problem classical geometry left unsolved

"Clouds are not spheres, mountains are not cones, and bark is not smooth."

Benoît B. Mandelbrot, The Fractal Geometry of Nature, 1982

Smooth shapes describe invented things, not found things

Euclidean figures — lines, circles, cones — fit machines and drawings. Rivers, coastlines, lungs and lightning obey no such formulas.

Roughness is a property, not a defect

A coastline gets longer the closer you look; its length is meaningless — but its fractal dimension is roughly constant at every scale.

Computers made the invisible visible

Iteration theory from 1918 predicted geometries like these. Only computing gave them to the eye — and M was the first.

02 · Basic concept

Working in the complex plane

Every point we will ever test is a complex number — two real coordinates wearing one name.

A point in the plane $$c = a + bi, \qquad i^2 = -1$$
Two axes. Rea runs horizontally, Imb vertically. We test roughly a ∈ [−2.00, +0.70], b ∈ [−1.20, +1.20].
One screen = one complex plane. Each pixel is a number c. The set M simply records the fate of z₀ = 0 under repeated squaring-and-adding-c.
A point c in the plane — its orbit under z² + c decides membership
02 · Basic concept

One rule, endlessly repeated

The whole set comes from a single instruction applied again and again. Membership is decided by what the orbit does.

The recurrence — square, then add c $$z_0 = 0, \qquad z_{n+1} = z_n^2 + c$$
Definition of the set $$\mathcal{M} = \bigl\{\, c \in \mathbb{C} \;:\; \text{the orbit of } 0 \text{ stays bounded}\,\bigr\}$$
equivalently lim sup |z\u2099| ≤ 2

Two numbers enter — c stays fixed; only z moves. Two outcomes are possible: the orbit stays near the origin, or it flies away to infinity. Nothing in between matters very much.

Bounded — inside M c = 0
0 → 0 → 0 → 0 → …

The orbit never leaves the disk |z| ≤ 2 — forever. So c = 0 belongs to the set.

Escaping — outside M c = 1
0 → 1 → 2 → 5 → 26 → …

Once past |z| > 2 the size of z explodes. At step 3 the orbit has escaped — so c = 1 is not in the set.

Two fates, one question. Bounded or not? The answer — computed for millions of c — draws the set (slide 07).

1. Pick a screen pixel → read off its complex number c. 2. Iterate z\u2099 from 0, again and again — count the steps until (or unless) |z| exceeds 2. 3. No escape → paint it solid ink (∈ M). Escaped at step n → paint by that count. 4. Do it ~2–3 million times. The picture assembles itself.
Why colour by n? The step number carries information — it shades the outside and later feeds the smooth-colouring formula (slide 09). Colour is data, not decoration.

Example above is hand-computed; the live slide (10) runs this construction while you watch.

04 · Algorithm & properties

Why radius two decides everything

We never simulate forever — we don't have to. One number, 2, cuts the work down to a handful of iterations.

The escape theorem $$|z_n| > 2 \;\Longrightarrow\; \bigl|z_{n+1}\bigr| \;\ge\; |z_n|\,\bigl(|z_n| - 1\bigr) \;>\; |z_n|$$

Once |z\u2099| > 2 and |c| ≤ 2, the growth factor (|z\u2099|−1) > 1. Every later step is larger than the last — the orbit is forced to infinity. It can never come back.

The GPU shortcut $$\underbrace{\sqrt{x^2 + y^2} > 2}_{\text{needs a square root}} \quad\Longleftrightarrow\quad \underbrace{\,x^2 + y^2 > 4\,}_{\text{two multiplications}}$$

Across a 1024·768 plot of ~790k pixels, skipping the sqrt on every iteration keeps the whole construction fast enough to run live.

And if it never escapes? We cap the count (say n = 100). Reaching the cap without crossing radius 2 is taken as membership — an approximation, and a good one for any finite screen.
Growth of |z\u2099| for c = 1 — the radius 2 line is a one-way door
04 · Algorithm & properties

Smooth colour on a rough boundary

Two refinements make the picture both prettier and truer: continuous shading, and a boundary too intricate to draw.

Continuous potential · smooth escape count $$\nu(c) = n + 1 - \frac{\log\bigl(\log|z_n|\bigr)}{\log 2}$$

Replaces the integer step count with a real "escape potential". Result: no visible colour bands at any zoom depth — the gradient flows without breaking.

Fractal dimension of the boundary $$\dim_H\bigl(\partial\,\mathcal{M}\bigr) = 2$$

Shishikura, 1998: the boundary is so convoluted that it is space-filling — dimension 2, up there with the plane itself. Every magnification shows new, equally intricate structure.

06 · Applications

From pure mathematics to the real world

The same signature — self-similar structure, deep sensitivity to a single parameter — shows up in four very different industries.

Fractal antennas

Self-similar shapes resonate at several bands at once — one compact antenna carries 5G, Wi-Fi and GPS. Dimensions shrink to a fraction of a conventional dipole. VERIFY

Procedural scenery — games & film

Mountain ranges, clouds, coastlines and bark are generated from fractal rules rather than hand-modeled geometry — infinite detail, tiny storage.

Chaos in cryptography

Sensitivity to initial conditions makes iterated maps good sources of pseudo-random numbers — promising material for keystreams and secure multiplexing. VERIFY

Fractal (IFS) compression

Store a scene as the few shrinking maps that regenerate it — a radical idea from Barnsley. Real-world adoption was modest, but it pushed the field of image coding.VERIFY

08 · Conclusion

What a single map teaches

i.Simplicity → complexity

One quadratic rule, repeated, manufactures detail that never ends — complexity is an outcome, not an input.

ii.One equation, many fields

The same map bridges complex analysis, dynamics, computation and graphics — a single object studied from four directions.

iii.Practice followed theory

1918 mathematics, 1980 hardware, 1990s engineering, open questions today — each century's tool unlocked the next.

"Bottomless wonders spring from simple rules, repeated without end." — Benoît B. Mandelbrot
